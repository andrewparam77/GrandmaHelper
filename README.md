# BabaControl

Один APK — два режима. Помощник управляет телефоном бабушки.

## Установка
1. Скачай APK из Actions → последний workflow → Artifacts
2. Установи на оба телефона
3. На её телефоне: «Это телефон бабушки» → включи Accessibility
4. На своём: «Я — помощник»
5. Одинаковый код комнаты на обоих

## Firebase
URL задаётся в `Prefs.kt` → константа `FB`.
